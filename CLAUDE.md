# Blueberry

The live repo: the site, and at `src/game/` under `#/app`, the learning game.
Rulebook: `documentation/CLAUDE-blueberry-game.md`. Read the section you
need, not the file. Working with Andrew and the shell load from
`../../CLAUDE.md`.

## Start here, read less
- `documentation/STATUS.md` is current state in under 100 lines. Read it
  before exploring
- Big docs by section: Grep the heading, Read that range.
  `TRAINER-INVENTORY.md` ~1,900 lines, `COURSE-OUTLINE-ORGO2.md` ~770
- Never open `docs/`, `dist/` or `.gauntlet/`: build output and
  screenshots, ~275MB
- Iterate on one file (`npx vitest run <path>`); full `npm test` once
  before calling it done
- `src/game/test/bootLoader.test.ts` is red on purpose, see
  `documentation/BOOT-LOADER-BLOCKER.md`. Do not investigate it

## Traps that already cost hours
- Prose goes in `documentation/`. `docs/` is gitignored and wiped on publish
- Game URLs come from `src/game/app/routes.ts`; a hand-built hash misses
  `#/app`. A new route also needs a row in `src/lib/useDocumentTitle.ts`
- chem-core and feedback load from compiled `dist/`. After editing either,
  `npm run build:packages` or dev and tests run stale code
- Dev server is pinned to 5173 for Google sign-in. If busy, free the port. If a page
  serves the WRONG PROJECT, two vite servers are splitting the stacks: `strictPort`
  does not catch that, because one binds `127.0.0.1:5173` and the other `[::1]:5173`
  and both start clean. Windows prefers `::1`, so `localhost:5173` serves whichever
  won IPv6. Check with `Get-NetTCPConnection -LocalPort 5173 -State Listen`. The
  dashboard moved to 5174 on 2026-09-24 for this reason
- `packages/validators/tests/` is in no vitest config; `npm test` skips it
- Other sessions leave uncommitted edits. Stage your files by path
- `validators.lock.json` is regenerated by the owner only, own commit

## Non-negotiable: security and money
- No secret in a `VITE_` variable; those ship in the public bundle
- Money and access are enforced server side (Edge Function or RLS)
- RLS on every user table, plus a column GRANT on entitlement columns
- Ketcher and any multi-MB import stay behind `React.lazy`
- Chemistry shown to a student is derived with RDKit, never recalled
